Rust는 타입 안전성과 메모리 안전성을 보장하는 정적 타입 언어입니다.

> **핵심 정리** · Rust의 변수는 기본적으로 불변이며 `mut` 키워드로 가변으로 만듭니다. 소유권 이동(move)은 값이 할달될 때 소유권이 이전되며, Copy 트레이트 타입은 복사됩니다. 스택은 고정 크기 데이터를 빠르게 할당하고, 힙은 가변 크기 데이터를 동적으로 할당합니다. String은 힙에 UTF-8 바이트를 저장하고, &str은 슬라이스로 참조합니다.


## 수업 목표

- let과 mut 키워드의 차이를 이해합니다.
- 소유권 이동(move semantics)을 이해합니다.
- Copy 트레이트의 동작을 이해합니다.
- 스택과 힙 할당의 차이를 이해합니다.
- Rust의 기본 데이터 타입과 메모리 구조를 이해합니다.

## 변수 선언과 불변성

```rust
fn main() {
    // 불변 변수 (기본)
    let x = 5;
    // x = 10;  // 컴파일 에러: cannot assign twice to immutable variable

    // 가변 변수
    let mut y = 5;
    y = 10;

    // 변수 섀도잉 (shadowing)
    let x = x + 1;
    let x = "새로운 값";

    println!("x: {}, y: {}", x, y);
}
```

`let x = 5`는 불변 변수를 선언합니다. Rust의 기본 철학은 불변성으로, 이는 데이터 레이스를 방지하고 코드를 예측 가능하게 만듭니다. `let mut y = 5`는 가변 변수를 선언하여 값을 변경할 수 있게 합니다. 변수 섀도잉은 동일한 이름으로 새 변수를 선언하는 것으로, 타입 변경도 가능합니다. `let x = x + 1`은 이전 `x`의 값을 사용하여 새 `x`를 선언합니다.

### 소유권 이동 (Move Semantics)

```rust
fn main() {
    // String은 힙 할당 타입
    let s1 = String::from("hello");
    let s2 = s1;  // s1의 소유권이 s2로 이동

    // println!("{}", s1);  // 컴파일 에러: value borrowed after move

    println!("{}", s2);  // 정상

    // 정수는 Copy 트레이트 구현
    let x = 5;
    let y = x;  // x가 복사됨 (이동 아님)

    println!("x: {}, y: {}", x, y);  // 둘 다 유효
}
```

`let s2 = s1`에서 `s1`의 소유권이 `s2`로 이동(move)합니다. `s1`은 더 이상 유효하지 않아 사용할 수 없습니다. 이는 이중 해제(double free)를 방지하기 위함입니다. `String`은 힙에 데이터를 할당하므로 소유권 이동이 필요합니다. 정수형 `x`는 Copy 트레이트를 구현하므로 `let y = x`는 복사(copy)가 발생하고 `x`는 여전히 유효합니다.

### Copy 트레이트

```rust
#[derive(Debug, Copy, Clone)]
struct Point {
    x: i32,
    y: i32,
}

fn main() {
    let p1 = Point { x: 1, y: 2 };
    let p2 = p1;  // Copy 트레이트로 복사됨

    println!("p1: {:?}, p2: {:?}", p1, p2);  // 둘 다 유효
}
```

Copy 트레이트를 구현한 타입은 할당 시 복사됩니다. Copy를 구현하려면 Clone도 구현해야 하며, 타입의 모든 필드도 Copy를 구현해야 합니다. Copy 타입: 모든 정수형, 불리언, char, 튜플(모든 필드가 Copy인 경우). Copy가 아닌 타입: String, Vec, 모든 힙 할당 타입.

## 기본 데이터 타입

### 정수형

```rust
fn main() {
    // 부호 있는 정수
    let i8_val: i8 = 127;          // 1바이트 (-128 ~ 127)
    let i16_val: i16 = 32767;      // 2바이트
    let i32_val: i32 = 2147483647; // 4바이트 (기본)
    let i64_val: i64 = 9223372036854775807; // 8바이트
    let i128_val: i128 = 170141183460469231731687303715884105727; // 16바이트

    // 부호 없는 정수
    let u8_val: u8 = 255;          // 1바이트 (0 ~ 255)
    let u16_val: u16 = 65535;     // 2바이트
    let u32_val: u32 = 4294967295; // 4바이트
    let u64_val: u64 = 18446744073709551615; // 8바이트
    let u128_val: u128 = 340282366920938463463374607431768211455; // 16바이트

    // 플랫폼 의존적
    let isize_val: isize = 42;     // 포인터 크기 (32비트: 4바이트, 64비트: 8바이트)
    let usize_val: usize = 42;     // 인덱싱에 사용

    println!("정수형: {}, {}, {}", i32_val, u64_val, usize_val);
}
```

Rust의 정수형은 크기와 부호에 따라 12가지로 세분화됩니다. `i32`가 기본 정수형이며, 특별한 이유가 없으면 `i32`를 사용하는 것이 관례입니다. `isize`와 `usize`는 포인터 크기와 동일하여 컬렉션 인덱싱에 사용됩니다. 정수 리터럴은 타입 추론이 가능하며, `1000i64`처럼 접미사로 명시할 수도 있습니다.

### 부동소수점

```rust
fn main() {
    let f32_val: f32 = 3.14159;   // 4바이트 (IEEE 754)
    let f64_val: f64 = 3.141592653589793; // 8바이트 (기본)

    println!("f32: {}, f64: {}", f32_val, f64_val);
}
```

`f64`가 기본 부동소수점 타입이며, 특별한 이유가 없으면 `f64`를 사용합니다. Rust는 IEEE 754 표준을 따르며, NaN과 Infinity를 지원합니다.

### 문자열

```rust
fn main() {
    // String — 힙 할당, 가변, 소유권 있는 문자열
    let s1: String = String::from("hello");
    let mut s2: String = String::new();
    s2.push_str("world");

    // &str — 문자열 슬라이스, 불변 참조
    let s3: &str = "hello";        // 문자열 리터럴
    let s4: &str = &s1[0..5];      // String의 슬라이스

    println!("String: {}, &str: {}, {}", s1, s3, s4);
}
```

`String`은 힙에 UTF-8 바이트 시퀀스를 저장하는 가변 버퍼입니다. 내부적으로 `Vec<u8>`의 래퍼로 구현되어 있으며, 길이, 용량, 포인터를 가집니다. `&str`은 문자열의 일부를 참조하는 슬라이스로, 소유권 없이 문자열 데이터를 읽을 수 있습니다. 문자열 리터럴 `"hello"`는 `&'static str` 타입으로, 프로그램 실행 내내 유효합니다.

### 불리언과 문자

```rust
fn main() {
    let t: bool = true;
    let f: bool = false;

    let c: char = 'A';              // 유니코드 스칼라 (4바이트)
    let emoji: char = '😀';         // 이모지도 가능

    println!("bool: {}, {}, char: {}, {}", t, f, c, emoji);
}
```

`bool`은 1바이트를 차지하며 `true` 또는 `false` 값만 가집니다. `char`는 유니코드 스칼라 값을 저장하며 4바이트를 차지합니다. ASCII가 아닌 문자도 표현할 수 있습니다.

### 배열과 벡터

```rust
fn main() {
    // 배열 — 고정 크기, 스택 할당
    let arr: [i32; 5] = [1, 2, 3, 4, 5];
    let first = arr[0];

    // 벡터 — 가변 크기, 힙 할당
    let mut vec: Vec<i32> = Vec::new();
    vec.push(1);
    vec.push(2);
    vec.push(3);

    let vec2 = vec![1, 2, 3];      // 매크로로 초기화

    println!("배열: {:?}, 벡터: {:?}", arr, vec);
}
```

배열 `[T; N]`은 고정 크기 N의 타입 T 시퀀스로 스택에 할당됩니다. 벡터 `Vec<T>`는 가변 크기의 동적 배열로 힙에 할당됩니다. `vec!` 매크로로 간단히 초기화할 수 있습니다.

## 스택과 힙 할당

```rust
fn main() {
    // 스택 할당 — 고정 크기, 빠름
    let x: i32 = 42;
    let y: i32 = 100;

    // 힙 할당 — 가변 크기, 느림
    let s: String = String::from("hello");

    println!("스택: {}, 힙: {}", x, s);
}
```

스택은 함수 호출 시 push, 종료 시 pop으로 LIFO 방식으로 메모리를 할당/해제합니다. 고정 크기 데이터만 저장할 수 있으며 매우 빠릅니다. 힙은 동적으로 메모리를 할당하며 가변 크기 데이터를 저장할 수 있습니다. 할당과 해제에 비용이 발생합니다. Rust는 소유권 시스템으로 힙 메모리의 수명을 컴파일 타임에 추적합니다.


## 사람들이 자주 묻는 질문

<details>
<summary><strong>Q: 왜 Rust는 기본적으로 불변 변수인가요?</strong></summary>

Rust의 기본 철학은 불변성으로, 이는 다음 이유로 안전성을 높입니다: (1) **데이터 레이스 방지**: 불변 데이터는 여러 스레드에서 안전하게 공유될 수 있습니다. (2) **코드 예측 가능성**: 값이 변경되지 않음을 보장하여 코드 추론이 쉬워집니다. (3) **컴파일러 최적화**: 불변성은 컴파일러가 더 공격적인 최적화를 수행할 수 있게 합니다. 가변성이 필요할 때만 `mut` 키워드를 명시적으로 사용하여 의도를 명확히 합니다.
</details>

<details>
<summary><strong>Q: 소유권 이동(move)이 발생하는 시점은 언제인가요?</strong></summary>

소유권 이동은 다음 경우에 발생합니다: (1) **할당**: `let s2 = s1`에서 `s1`이 힙 할당 타입(String, Vec 등)이면 소유권이 이동합니다. (2) **함수 인자 전달**: `fn take(s: String)`으로 호출하면 소유권이 함수로 이동합니다. (3) **함수 반환**: `fn give() -> String`으로 반환하면 소유권이 호출자로 이동합니다. Copy 트레이트를 구현한 타입(정수, 불리언 등)은 대신 복사가 발생합니다.
</details>

<details>
<summary><strong>Q: String과 &str의 차이는 무엇인가요?</strong></summary>

`String`은 힙에 할당된 소유권 있는 문자열입니다. 내부적으로 포인터, 길이, 용량을 가지며, 크기를 변경할 수 있습니다. `&str`은 문자열의 일부를 참조하는 슬라이스로, 소유권이 없습니다. 문자열 리터럴 `"hello"`는 `&'static str` 타입입니다. 함수 인자로 문자열을 받을 때 소유권이 필요 없으면 `&str`을, 소유권이 필요하면 `String`을 사용합니다.
</details>

<details>
<summary><strong>Q: 스택과 힙 중 어디에 할당되는지가 왜 중요한가요?</strong></summary>

성능과 메모리 관리 때문입니다: (1) **스택 할당**: 포인터 조작만으로 할당/해제되어 매우 빠릅니다(O(1)). 하지만 크기가 컴파일 타임에 알려져야 합니다. (2) **힙 할당**: 할당자(allocator)를 통해 메모리를 찾고 해제해야 하므로 느립니다. 하지만 가변 크기 데이터를 저장할 수 있습니다. Rust는 소유권 시스템으로 힙 메모리의 수명을 추적하여 가비지 컬렉터 없이도 안전하게 관리합니다.
</details>

<details>
<summary><strong>Q: 배열과 벡터 중 언제 어떤 것을 사용해야 하나요?</strong></summary>

배열은 크기가 컴파일 타임에 알려져 있을 때 사용합니다: 고정 크기 버퍼, 행렬, 픽셀 데이터 등. 스택에 할당되어 빠릅니다. 벡터는 크기가 런타임에 변할 때 사용합니다: 동적 리스트, 사용자 입력, 파일 내용 등. 힙에 할당되어 느리지만 유연합니다. Rust는 `vec.into_boxed_slice()`로 벡터를 고정 크기 배열로 변환할 수도 있습니다.
</details>
