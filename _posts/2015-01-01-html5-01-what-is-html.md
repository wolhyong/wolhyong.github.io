웹 개발을 시작하려면 HTML부터 배우는 게 맞습니다. CSS도, JavaScript도 결국 HTML 위에서 동작하기 때문입니다. 이 글에서는 HTML이 정확히 무엇인지, 브라우저가 어떻게 웹 페이지를 그려내는지 기초부터 짚어봅니다.

---

## HTML이 무엇인지 한 문장으로 정리하면

**HTML(HyperText Markup Language)** 은 웹 페이지의 구조를 만드는 언어입니다.

프로그래밍 언어처럼 조건문이나 반복문을 쓰는 게 아닙니다. 태그(tag)라는 기호를 이용해 "이건 제목이다", "이건 문단이다", "이건 이미지다" 하는 식으로 콘텐츠의 역할을 표시합니다. 그래서 마크업 언어라고 부릅니다.

HyperText는 링크를 통해 다른 문서로 이동할 수 있다는 의미입니다. 지금 우리가 클릭 한 번으로 다른 페이지로 넘어가는 것이 바로 하이퍼텍스트 덕분입니다.

---

## 브라우저가 HTML을 읽는 방법

주소창에 URL을 입력하면 다음 순서로 페이지가 화면에 나타납니다.

1. 브라우저가 서버에 해당 주소의 파일을 요청합니다
2. 서버가 HTML 파일을 응답으로 보냅니다
3. 브라우저가 HTML을 위에서부터 한 줄씩 읽습니다
4. 태그를 만날 때마다 화면에 무엇을 그릴지 결정합니다
5. CSS와 JavaScript도 추가로 불러와 스타일과 동작을 붙입니다

결국 HTML 파일은 브라우저에게 보내는 **설계도**입니다.

---

## 태그란 무엇인가

HTML의 핵심은 태그입니다. 태그는 꺾쇠 괄호(`< >`)로 감싼 키워드입니다.

```html
<p>안녕하세요. 이것은 문단입니다.</p>
```

`<p>`는 여는 태그, `</p>`는 닫는 태그입니다. 둘 사이에 있는 내용이 "문단"으로 처리됩니다.

**열고 닫는 태그 (쌍 태그)**

```html
<h1>제목입니다</h1>
<p>문단 내용입니다.</p>
<a href="https://example.com">링크 텍스트</a>
```

**혼자 쓰는 태그 (빈 태그)**

```html
<img src="photo.jpg" alt="사진 설명">
<br>
<hr>
```

이미지나 줄 바꿈처럼 내용을 담을 필요가 없는 태그는 닫는 태그 없이 단독으로 씁니다.

---

## 속성(Attribute)이란

태그 안에 추가 정보를 넣을 때 속성을 사용합니다. `이름="값"` 형태로 여는 태그 안에 씁니다.

```html
<a href="https://google.com" target="_blank">구글로 이동</a>
```

`href`는 이동할 주소를 지정하는 속성, `target="_blank"`는 새 탭에서 열라는 속성입니다.

---

## HTML5가 이전 버전과 다른 점

현재 표준은 HTML5입니다. 2014년에 공식 표준이 됐으며 이전 버전과 달라진 점이 있습니다.

**추가된 것들**
- `<video>`, `<audio>` 태그로 플러그인 없이 미디어 재생 가능
- `<header>`, `<nav>`, `<article>`, `<footer>` 등 의미 있는 구조 태그 추가
- Canvas로 그래픽 처리 가능
- 로컬 저장소, 웹소켓 등 다양한 API 제공

**권장하지 않게 된 것들**
- `<font>`, `<center>`, `<big>` 같은 표현용 태그는 사용 자제
- 스타일은 CSS로만 처리하는 방향으로 정리됨

## 첫 번째 HTML 파일 만들기

메모장이나 VS Code를 열고 아래 내용을 입력한 다음 `index.html`로 저장합니다.

```html
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>내 첫 번째 웹 페이지</title>
</head>
<body>
  <h1>안녕하세요!</h1>
  <p>이것은 제가 처음 만든 HTML 파일입니다.</p>
</body>
</html>
```

저장 후 파일을 더블 클릭하면 브라우저에서 바로 열립니다. "안녕하세요!"라는 제목과 문단이 화면에 보이면 성공입니다.

---

## 정리

- HTML은 웹 페이지의 구조를 만드는 마크업 언어입니다
- 태그(`<태그명>`)로 콘텐츠의 역할을 표시합니다
- 태그 안에 속성을 추가해 더 구체적인 정보를 넣을 수 있습니다
- 현재 표준은 HTML5이며 시맨틱 태그와 멀티미디어 지원이 강화됐습니다

다음 글에서는 HTML 파일의 기본 구조인 `DOCTYPE`, `<html>`, `<head>`, `<body>` 태그를 자세히 다룹니다.
