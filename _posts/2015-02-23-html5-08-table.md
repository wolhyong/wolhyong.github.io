데이터를 행과 열로 표현해야 할 때 테이블을 사용합니다. 가격 비교표, 시간표, 스펙 비교, 통계 데이터 등이 대표적인 예입니다.

그런데 테이블을 배울 때 초보자가 가장 많이 하는 실수는 "이거로 레이아웃도 만들 수 있겠네"라고 생각하는 것입니다. 과거에는 실제로 테이블로 웹사이트 전체 레이아웃을 만들기도 했습니다. 하지만 지금은 절대 그렇게 쓰지 않습니다. 테이블은 오직 데이터를 표시하는 용도로만 씁니다. 이 이유를 끝까지 읽으면 이해할 수 있습니다.

일단 기본 태그 구조부터 하나씩 짚어보겠습니다.

---

## 기본 구조

```html
<table>
  <tr>
    <th>이름</th>
    <th>언어</th>
    <th>레벨</th>
  </tr>
  <tr>
    <td>React</td>
    <td>JavaScript</td>
    <td>중급</td>
  </tr>
  <tr>
    <td>Django</td>
    <td>Python</td>
    <td>중급</td>
  </tr>
</table>
```

- `table` — 테이블 전체를 감싸는 태그
- `tr` (Table Row) — 행 하나
- `th` (Table Header) — 헤더 셀. 브라우저에서 자동으로 굵게, 가운데 정렬로 표시됩니다
- `td` (Table Data) — 일반 데이터 셀

이 코드를 브라우저에서 열어보면 이름, 언어, 레벨이 표 머리글 행에 굵게 표시되고 아래에 각 데이터가 행으로 배열됩니다. 테두리는 아직 안 보이는데, 기본 HTML 테이블에는 테두리가 없기 때문입니다. 나중에 CSS로 border를 추가하면 깔끔한 표가 완성됩니다.

---

## thead, tbody, tfoot으로 구조 나누기

테이블을 헤더, 본문, 푸터로 명확히 나눌 수 있습니다.

```html
<table>
  <thead>
    <tr>
      <th>프레임워크</th>
      <th>언어</th>
      <th>GitHub 스타</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>React</td>
      <td>JavaScript</td>
      <td>220,000+</td>
    </tr>
    <tr>
      <td>Vue.js</td>
      <td>JavaScript</td>
      <td>206,000+</td>
    </tr>
    <tr>
      <td>Angular</td>
      <td>TypeScript</td>
      <td>90,000+</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td colspan="3">데이터 기준: 2024년 12월</td>
    </tr>
  </tfoot>
</table>
```

이렇게 나누면 CSS 스타일을 각 영역에 독립적으로 적용할 수 있고, 스크린 리더가 테이블 구조를 올바르게 읽어줍니다.

---

## scope 속성 — 접근성 향상

th 태그에 scope를 추가하면 스크린 리더가 어느 행/열의 헤더인지 정확히 파악합니다.

```html
<thead>
  <tr>
    <th scope="col">이름</th>
    <th scope="col">가격</th>
    <th scope="col">재고</th>
  </tr>
</thead>
<tbody>
  <tr>
    <th scope="row">MacBook Pro</th>
    <td>3,490,000원</td>
    <td>있음</td>
  </tr>
</tbody>
```

- `scope="col"` — 이 헤더가 해당 열 전체를 나타냄
- `scope="row"` — 이 헤더가 해당 행 전체를 나타냄

---

## colspan — 열 합치기

셀이 여러 열에 걸쳐 표시되도록 합니다.

```html
<table>
  <tr>
    <th colspan="3">상반기 매출 현황</th>
  </tr>
  <tr>
    <th>1분기</th>
    <th>2분기</th>
    <th>합계</th>
  </tr>
  <tr>
    <td>1,200만원</td>
    <td>1,500만원</td>
    <td>2,700만원</td>
  </tr>
</table>
```

`colspan="3"`은 이 셀이 3개 열을 차지한다는 뜻입니다.

---

## rowspan — 행 합치기

셀이 여러 행에 걸쳐 표시되도록 합니다.

```html
<table>
  <tr>
    <th>카테고리</th>
    <th>기술</th>
  </tr>
  <tr>
    <td rowspan="3">프론트엔드</td>
    <td>HTML</td>
  </tr>
  <tr>
    <td>CSS</td>
  </tr>
  <tr>
    <td>JavaScript</td>
  </tr>
</table>
```

"프론트엔드" 셀이 3개 행을 차지합니다.

---

## caption — 테이블 제목

테이블에 제목을 붙이는 태그입니다. table 태그 바로 안쪽 첫 번째로 씁니다.

```html
<table>
  <caption>2024년 프로그래밍 언어 인기 순위</caption>
  <thead>
    ...
  </thead>
</table>
```

시각적으로도 보이고, 스크린 리더가 테이블을 읽기 전에 먼저 읽어줍니다.

---

## 테이블 레이아웃에 쓰지 말 것

과거에는 테이블로 웹 페이지 전체 레이아웃을 만들었습니다. 지금은 절대로 해선 안 됩니다.

- 접근성 문제: 스크린 리더가 데이터 표로 해석
- SEO 문제: 콘텐츠 파악이 어려워짐
- 유지보수 문제: 코드가 매우 복잡해짐

레이아웃은 CSS Flexbox나 Grid로 만들어야 합니다. 테이블은 오직 **표 형태의 데이터**를 표현할 때만 사용합니다.

## 실습: 요금제 비교표 만들기

```html
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>요금제 비교</title>
</head>
<body>
  <table>
    <caption>호스팅 서비스 요금제 비교 (월 기준)</caption>
    <thead>
      <tr>
        <th scope="col">기능</th>
        <th scope="col">무료</th>
        <th scope="col">스타터</th>
        <th scope="col">프로</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <th scope="row">저장 공간</th>
        <td>1GB</td>
        <td>10GB</td>
        <td>100GB</td>
      </tr>
      <tr>
        <th scope="row">대역폭</th>
        <td>10GB/월</td>
        <td>100GB/월</td>
        <td>무제한</td>
      </tr>
      <tr>
        <th scope="row">커스텀 도메인</th>
        <td>불가</td>
        <td>1개</td>
        <td>무제한</td>
      </tr>
      <tr>
        <th scope="row">가격</th>
        <td>무료</td>
        <td>9,900원</td>
        <td>29,900원</td>
      </tr>
    </tbody>
  </table>
</body>
</html>
```

---

## 마치며
- `table > tr > td/th` 가 기본 구조입니다
- `thead`, `tbody`, `tfoot`으로 테이블을 논리적으로 나눕니다
- `th`에 `scope` 속성을 추가하면 접근성이 향상됩니다
- `colspan`은 열 합치기, `rowspan`은 행 합치기입니다
- 테이블은 데이터 표시 용도로만, 레이아웃에는 절대 사용하지 않습니다
