HTML에서 텍스트를 다루는 태그 중 가장 기본이 되는 것이 제목 태그와 문단 태그입니다. 단순해 보이지만 잘못 사용하면 SEO와 접근성에 나쁜 영향을 줍니다. 올바른 사용법을 알아봅니다.

---

## 제목 태그 h1~h6

HTML에는 6단계의 제목 태그가 있습니다.

```html
<h1>가장 큰 제목 (페이지 대표 제목)</h1>
<h2>두 번째 제목 (주요 섹션 제목)</h2>
<h3>세 번째 제목 (소제목)</h3>
<h4>네 번째 제목</h4>
<h5>다섯 번째 제목</h5>
<h6>여섯 번째 제목</h6>
```

숫자가 작을수록 더 상위의 제목입니다. 책으로 비유하면 h1은 책 제목, h2는 챕터 제목, h3는 소단원 제목과 같습니다.

---

## h1은 페이지당 하나만

가장 기본적인 규칙입니다. `<h1>`은 한 페이지에 하나만 사용해야 합니다.

검색 엔진은 h1을 보고 이 페이지가 무엇에 관한 내용인지 판단합니다. h1이 여러 개면 "중심 주제가 뭔지 모르겠다"고 해석할 수 있습니다.

```html
<!-- 잘못된 사용 -->
<h1>HTML 입문 강의</h1>
<h1>첫 번째 수업</h1>  <!-- h1을 두 번 쓰면 안 됨 -->

<!-- 올바른 사용 -->
<h1>HTML 입문 강의</h1>
<h2>첫 번째 수업 — HTML이란?</h2>
```

---

## 계층 구조를 지켜야 하는 이유

제목 태그는 순서대로 사용해야 합니다. h1 다음에 h3를 쓰거나, h2 없이 h4를 쓰면 문서 구조가 깨집니다.

```html
<!-- 잘못된 구조 (h2를 건너뜀) -->
<h1>페이지 제목</h1>
<h3>소제목</h3>   <!-- h2 없이 h3 사용 -->

<!-- 올바른 구조 -->
<h1>페이지 제목</h1>
<h2>섹션 제목</h2>
<h3>소제목</h3>
```

스크린 리더 사용자는 제목 태그를 이용해 페이지를 탐색합니다. 계층이 어긋나면 탐색이 어려워집니다.

---

## 크기 때문에 h 태그를 고르면 안 됨

초보자들이 자주 하는 실수입니다. "이 텍스트를 크게 보이고 싶다"는 이유로 h 태그를 선택하면 안 됩니다.

```html
<!-- 잘못된 사용: 시각적 크기 때문에 h 태그 선택 -->
<h3>그냥 굵게 보이고 싶어서 h3 사용</h3>

<!-- 올바른 방법: 크기는 CSS로 조절 -->
<p style="font-size: 1.2rem; font-weight: bold;">굵은 텍스트</p>
```

h 태그는 **문서의 구조와 계층**을 나타내는 태그입니다. 시각적 표현은 CSS의 몫입니다.

---

## 문단 태그 p

텍스트 블록 하나를 문단으로 묶는 태그입니다.

```html
<p>첫 번째 문단입니다. 브라우저는 p 태그 사이에 자동으로 여백을 만듭니다.</p>
<p>두 번째 문단입니다. 새 줄에서 시작하고 위아래 여백이 생깁니다.</p>
```

p 태그는 블록 요소라서 자동으로 새 줄에서 시작하고, 위아래로 마진이 생깁니다.

---

## 줄 바꿈 br

문단을 새로 시작하지 않고 단순히 줄을 바꿀 때 사용합니다.

```html
<p>
  서울특별시 강남구<br>
  테헤란로 123<br>
  456호
</p>
```

주소처럼 같은 블록 안에서 줄을 나눠야 할 때 유용합니다. 단, 문단 구분이 필요하다면 br 대신 p 태그를 쓰는 것이 맞습니다.

```html
<!-- 잘못된 사용: p 대신 br로 문단 구분 -->
첫 번째 내용입니다.<br><br>
두 번째 내용입니다.<br><br>

<!-- 올바른 사용 -->
<p>첫 번째 내용입니다.</p>
<p>두 번째 내용입니다.</p>
```

---

## 수평선 hr

주제가 바뀌거나 내용을 시각적으로 구분할 때 사용하는 수평선입니다.

```html
<p>첫 번째 섹션 내용입니다.</p>

<hr>

<p>두 번째 섹션 내용입니다.</p>
```

단순히 줄을 그리는 용도보다, 주제 전환을 나타내는 의미적 구분선으로 사용합니다.

---

## 실습: 블로그 글 구조 만들기

```html
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>JavaScript 비동기 처리 이해하기</title>
</head>
<body>
  <h1>JavaScript 비동기 처리 이해하기</h1>

  <p>자바스크립트에서 비동기 처리는 개발자가 반드시 이해해야 하는 개념입니다. 콜백부터 async/await까지 순서대로 설명합니다.</p>

  <h2>1. 콜백 함수란?</h2>
  <p>콜백 함수는 다른 함수에 인수로 전달되어 나중에 호출되는 함수입니다.</p>

  <h3>콜백 지옥 문제</h3>
  <p>콜백이 중첩되면 코드가 오른쪽으로 계속 들여쓰여서 가독성이 크게 떨어집니다.</p>

  <hr>

  <h2>2. Promise란?</h2>
  <p>Promise는 비동기 작업의 결과를 나타내는 객체입니다. 콜백 지옥 문제를 해결하기 위해 도입됐습니다.</p>

  <h2>3. async/await</h2>
  <p>async/await는 Promise를 더 읽기 쉽게 작성할 수 있도록 ES2017에서 추가됐습니다.</p>
</body>
</html>
```

## 되짚기

- h1~h6은 문서의 계층 구조를 표현하는 제목 태그입니다
- h1은 한 페이지에 하나만 사용합니다
- 제목 계층은 순서대로 사용해야 합니다 (h1 → h2 → h3)
- p는 하나의 문단을 나타내는 태그입니다
- br은 줄 바꿈, hr은 주제 구분선입니다

다음 글에서는 텍스트를 강조하거나 꾸미는 태그들 (strong, em, span, blockquote)을 다룹니다.

## 자주 하는 실수와 주의점

초보자들이 제목 태그(h1~h6)와 문단 태그(p) 사용법을 다룰 때 가장 흔히 하는 실수는 닫는 태그를 빼먹거나 속성값을 따옴표로 감싸지 않는 것입니다. HTML은 오류에 관대한 편이지만, 이런 실수는 레이아웃이 깨지거나 스타일이 정상적으로 적용되지 않는 원인이 됩니다. 반드시 모든 태그가 올바르게 열고 닫혔는지, 속성값은 따옴표로 감쌌는지 확인하는 습관을 들이는 것이 좋습니다.

## 브라우저 동작 방식

브라우저는 HTML 문서를 위에서 아래로 읽으며 DOM(Document Object Model) 트리를 생성합니다. 제목 태그(h1~h6)와 문단 태그(p) 사용법 요소가 DOM 트리에서 어떻게 해석되고 배치되는지 이해하면 더 체계적인 마크업을 작성할 수 있습니다. 개발자 도구(F12)의 Elements 패널을 열어 실제 DOM 구조를 확인하는 습관을 추천합니다.

## 실전 활용 팁

실무에서는 제목 태그(h1~h6)와 문단 태그(p) 사용법을 단독으로 사용하기보다는 CSS와 JavaScript와 함께 조합하여 사용합니다. 시맨틱한 마크업은 검색 엔진 최적화(SEO)와 웹 접근성 향상에 직접적인 도움을 줍니다. 또한 W3C validator를 통해 HTML 문법을 검증하면 크로스 브라우징 이슈를 줄일 수 있습니다.
