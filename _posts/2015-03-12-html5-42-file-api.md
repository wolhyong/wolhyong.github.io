사용자가 선택한 파일을 서버에 보내기 전에 브라우저에서 읽고 처리할 수 있습니다. 이미지 미리보기, 텍스트 파일 내용 표시, 파일 유효성 검사 등이 대표적인 사용 사례입니다.

## File과 FileList

```html
<input type="file" id="file-input" multiple accept="image/*,.pdf,.txt">
```

```javascript
const input = document.getElementById('file-input');

input.addEventListener('change', (e) => {
  const fileList = e.target.files; // FileList 객체

  Array.from(fileList).forEach(file => {
    console.log(file.name);          // 파일명
    console.log(file.size);          // 바이트 단위 크기
    console.log(file.type);          // MIME 타입 (예: 'image/jpeg')
    console.log(file.lastModified);  // 수정 시각 (타임스탬프)
    console.log(new Date(file.lastModified).toLocaleString('ko-KR'));
  });
});
```

## FileReader — 파일 내용 읽기

```javascript
const reader = new FileReader();

// 완료 이벤트
reader.addEventListener('load', (e) => {
  console.log('읽기 완료:', e.target.result);
});

// 오류 이벤트
reader.addEventListener('error', () => {
  console.error('파일 읽기 오류');
});

// 진행 이벤트
reader.addEventListener('progress', (e) => {
  if (e.lengthComputable) {
    const pct = Math.round((e.loaded / e.total) * 100);
    console.log(`진행: ${pct}%`);
  }
});
```

**읽기 방식별 차이**

| 메서드 | 결과 형식 | 적합한 용도 |
|--------|----------|------------|
| `readAsText(file, encoding)` | 문자열 | 텍스트 파일, CSV, JSON |
| `readAsDataURL(file)` | Base64 Data URL | 이미지 미리보기 |
| `readAsArrayBuffer(file)` | ArrayBuffer | 바이너리 처리, 오디오/이미지 분석 |

## 이미지 미리보기 — Object URL (권장)

FileReader의 `readAsDataURL` 대신 `URL.createObjectURL`을 사용하면 훨씬 빠릅니다. Base64 변환 없이 메모리 참조만 만들기 때문입니다.

```javascript
function previewImage(file, imgElement) {
  // 이전 URL 해제 (메모리 누수 방지)
  if (imgElement.src.startsWith('blob:')) {
    URL.revokeObjectURL(imgElement.src);
  }

  const objectUrl = URL.createObjectURL(file);
  imgElement.src = objectUrl;

  // 이미지 로드 완료 후 URL 해제 (선택)
  // imgElement.onload = () => URL.revokeObjectURL(objectUrl);
}
```

```html
<input type="file" id="avatar-input" accept="image/*">
<img id="preview" alt="미리보기" style="max-width:200px; display:none">
```

```javascript
document.getElementById('avatar-input').addEventListener('change', (e) => {
  const file = e.target.files[0];
  if (!file) return;

  const preview = document.getElementById('preview');
  previewImage(file, preview);
  preview.style.display = 'block';
});
```

## 텍스트 파일 읽기

```javascript
function readTextFile(file) {
  return new Promise((resolve, reject) => {
    const reader = new FileReader();
    reader.onload = (e) => resolve(e.target.result);
    reader.onerror = () => reject(new Error('파일 읽기 실패'));
    reader.readAsText(file, 'UTF-8');
  });
}

// 마크다운 파일 미리보기
document.getElementById('md-input').addEventListener('change', async (e) => {
  const file = e.target.files[0];
  if (!file || !file.name.endsWith('.md')) return;

  try {
    const text = await readTextFile(file);
    document.getElementById('preview').textContent = text;
  } catch (err) {
    console.error(err);
  }
});
```

## CSV 파싱

```javascript
async function parseCSV(file) {
  const text = await readTextFile(file);
  const lines = text.trim().split('
');
  const headers = lines[0].split(',').map(h => h.trim());

  return lines.slice(1).map(line => {
    const values = line.split(',').map(v => v.trim());
    return Object.fromEntries(headers.map((h, i) => [h, values[i]]));
  });
}

// 사용
document.getElementById('csv-input').addEventListener('change', async (e) => {
  const rows = await parseCSV(e.target.files[0]);
  console.log('CSV 행 수:', rows.length);
  console.table(rows.slice(0, 5));
});
```

## FormData로 파일 업로드

```javascript
async function uploadFiles(files) {
  const formData = new FormData();

  Array.from(files).forEach((file, i) => {
    formData.append(`file_${i}`, file, file.name);
  });

  // 추가 데이터도 함께 전송 가능
  formData.append('uploader', 'wolhyong');
  formData.append('category', 'images');

  try {
    const response = await fetch('/api/upload', {
      method: 'POST',
      body: formData,
      // Content-Type은 자동으로 multipart/form-data로 설정됨
    });

    if (!response.ok) throw new Error(`HTTP ${response.status}`);
    return await response.json();
  } catch (err) {
    console.error('업로드 실패:', err);
    throw err;
  }
}
```

## 업로드 진행률 표시 (XMLHttpRequest)

`fetch`는 아직 업로드 진행률을 지원하지 않습니다. 진행률이 필요하면 XMLHttpRequest를 사용합니다.

```javascript
function uploadWithProgress(file, onProgress) {
  return new Promise((resolve, reject) => {
    const xhr = new XMLHttpRequest();
    const formData = new FormData();
    formData.append('file', file);

    xhr.upload.addEventListener('progress', (e) => {
      if (e.lengthComputable) {
        const pct = Math.round((e.loaded / e.total) * 100);
        onProgress(pct);
      }
    });

    xhr.addEventListener('load', () => {
      if (xhr.status >= 200 && xhr.status < 300) {
        resolve(JSON.parse(xhr.responseText));
      } else {
        reject(new Error(`업로드 실패: ${xhr.status}`));
      }
    });

    xhr.addEventListener('error', () => reject(new Error('네트워크 오류')));
    xhr.addEventListener('abort', () => reject(new Error('업로드 취소')));

    xhr.open('POST', '/api/upload');
    xhr.send(formData);
  });
}

// 사용
const progressBar = document.getElementById('progress');
await uploadWithProgress(file, (pct) => {
  progressBar.value = pct;
  progressBar.textContent = `${pct}%`;
});
```

## 파일 유효성 검사

```javascript
const ALLOWED_TYPES = ['image/jpeg', 'image/png', 'image/webp', 'application/pdf'];
const MAX_SIZE = 5 * 1024 * 1024; // 5MB

function validateFile(file) {
  const errors = [];

  if (!ALLOWED_TYPES.includes(file.type)) {
    errors.push(`허용되지 않는 파일 형식: ${file.type}`);
  }

  if (file.size > MAX_SIZE) {
    errors.push(`파일 크기 초과: ${(file.size / 1024 / 1024).toFixed(1)}MB (최대 5MB)`);
  }

  if (file.name.length > 100) {
    errors.push('파일명이 너무 깁니다 (최대 100자)');
  }

  return errors;
}

input.addEventListener('change', (e) => {
  Array.from(e.target.files).forEach(file => {
    const errors = validateFile(file);
    if (errors.length) {
      alert(`${file.name}:
${errors.join('
')}`);
      e.target.value = ''; // 선택 취소
    }
  });
});
```

## 이미지 크기 리사이즈 (Canvas 활용)

업로드 전 브라우저에서 이미지를 리사이즈해서 서버 부하와 전송 데이터를 줄입니다.

```javascript
function resizeImage(file, maxWidth, maxHeight, quality = 0.8) {
  return new Promise((resolve) => {
    const img = new Image();
    const objectUrl = URL.createObjectURL(file);
    img.src = objectUrl;

    img.onload = () => {
      URL.revokeObjectURL(objectUrl);

      let { width, height } = img;
      if (width > maxWidth || height > maxHeight) {
        const ratio = Math.min(maxWidth / width, maxHeight / height);
        width = Math.round(width * ratio);
        height = Math.round(height * ratio);
      }

      const canvas = document.createElement('canvas');
      canvas.width = width;
      canvas.height = height;
      canvas.getContext('2d').drawImage(img, 0, 0, width, height);

      canvas.toBlob(resolve, file.type, quality);
    };
  });
}

// 사용
const resized = await resizeImage(originalFile, 1200, 800, 0.85);
console.log(`원본: ${originalFile.size}, 리사이즈: ${resized.size}`);
await uploadFiles([new File([resized], originalFile.name, { type: resized.type })]);
```

## 정리

- `File` 객체로 파일명, 크기, MIME 타입을 확인합니다
- `URL.createObjectURL`은 이미지 미리보기에 가장 빠른 방법입니다
- `FileReader.readAsText`로 텍스트·CSV를, `readAsArrayBuffer`로 바이너리를 읽습니다
- `FormData` + `fetch`로 파일을 서버에 업로드합니다
- 진행률이 필요하면 `XMLHttpRequest`의 `upload.progress` 이벤트를 사용합니다
